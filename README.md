# Tenders
This study presents a methodology for evaluating and comparing the performance of supervised classification models applied to public tenders in the European Union. The proposed approach combines the Random Forest and Gradient Boosting algorithms with explainable artificial intelligence (XAI) techniques and a rule-based system to optimize the award process, identifying historical patterns associated with favorable decisions. We constructed a normalized dataset from public data acquired from the TED platform using a scalable ETL process with Apache Spark. We then performed exploratory analysis and classification modeling (multiclass for Experiment A; binary for Experiment B) in accordance with the Foundational Methodology for Data Science. We evaluated the models using confusion matrices and aggregated classification metrics, including accuracy, precision, recall, and F1-score. This allowed us to compare model performance and stability objectively. The results show that Random Forest consistently performs better than Gradient Boosting in both experiments. In Experiment A, which involves 21 activity classes, Random Forest reached an F1-macro of 0.3550. This is a modest but statistically significant improvement over the majority-class baseline (F1 = 0.32), although it offers limited practical benefit for minority classes. In Experiment B, which focused on binary SME award prediction, Random Forest achieved F1 = 0.7706 and AUC = 0.7096. These results are useful for making strategic decisions for SMEs. Random Forest outperforms both Gradient Boosting and a Decision Tree baseline in every fold in both experiments (Wilcoxon signed-rank test, one-sided p = 0.001). LIME-based local explanations and interpretable rules are incorporated to promote transparency. Although LIME fidelity is limited in both experiments (R² = 0.43 in Experiment A, R² = 0.16 in Experiment B), the generated rules function as actionable decision-support guidance for domain analysts. SHAP- or Anchor-based explanations are proposed as future enhancements.

# Purpose of the repository:

This repository contains the code, experimental notebooks, and methodological artefacts
used in the scientific article:

"Analysis of public tenders with rule-based systems to improve decision-making"

The purpose of this repository is to facilitate experimental reproducibility, verification of
results, and methodological evaluation by academic reviewers. The repository is presented as supplementary material to the article.
